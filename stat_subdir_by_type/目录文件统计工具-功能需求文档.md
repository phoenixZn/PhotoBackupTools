# 目录文件统计工具-功能需求文档

## 1. 文档目标

本文档用于定义「目录文件统计工具」（子目录按文件类型统计）的完整功能需求。  
目标是：将文档交付给任意开发者后，对方无需参考原始代码，也能重新设计并实现**功能等价**的程序（CLI + GUI）。

本文档对应当前仓库实现目录：`stat_subdir_by_type/`（与 `put_in_yymm_order/` 同级）。

---

## 2. 适用范围与运行环境

- 实现语言：Python 3
- 平台范围：Windows / macOS
- 路径处理：必须使用 `pathlib` 或 `os.path`，确保跨平台路径兼容
- GUI 框架：`tkinter`
- 可选依赖：`tkinterdnd2`（仅用于目录拖拽增强）

---

## 3. 交付物要求

至少包含以下文件（命名可调整，但职责必须等价）：

1. **CLI 核心脚本**（当前：`stat_subdir_by_type.py`）
   - 负责子目录扫描、类型计数、修改日期统计、统计 txt 生成、清理旧统计文件、结构化事件输出
2. **GUI 启动器脚本**（当前：`gui_launcher.py`）
   - 负责参数收集、执行确认、调用 CLI、展示日志与进度、独立清理按钮
   - 支持通过启动参数指定配置文件路径（默认 `gui_settings.json`）
3. **一键启动脚本**（当前：`start_gui.bat`，Windows）
   - 双击启动 GUI，并支持参数透传到 `gui_launcher.py`
4. **依赖清单**（当前：`requirements.txt`）
   - 至少包含可选拖拽依赖声明（`tkinterdnd2`）
5. **GUI 默认配置文件**（当前：`gui_settings.json`）
   - 用于持久化 GUI 常用参数（根目录、白名单、勾选项等）
6. **功能需求文档**（本文档）

---

## 4. 核心业务目标

给定一个「根目录」，遍历其下**一级子目录**（不将根目录自身作为统计对象），为每个子目录在**根目录内**生成一个对应的统计 txt 文件。

### 4.1 统计范围

- **子目录范围**：仅根目录的直接子文件夹（`root.iterdir()` 中 `is_dir()` 为真的项），按名称不区分大小写排序处理
- **文件范围**：每个子目录内**递归**统计所有文件（`rglob("*")` 且 `is_file()`）
- **输出位置**：统计 txt 写在**根目录**下，不写入各子目录内部
- **数量关系**：一级子目录数量 = 生成的统计 txt 数量（每个子目录至少尝试生成 1 个文件，含空子目录）

### 4.2 统计 txt 文件名规则

文件名用于概括该子目录内各扩展名的文件数量，格式：

```text
统计_{子目录名}_{扩展名1}({数量1})_{扩展名2}({数量2})....txt
```

规则细则：

| 项 | 规则 |
|---|---|
| 前缀 | 固定为 `统计_` |
| 子目录名 | 原名称；非法文件名字符 `<>:"/\|?*` 替换为 `_`；空名回退为 `_` |
| 扩展名 token | 小写、不含前导点（如 `jpg`、`mp4`）；无后缀文件记为 `无后缀` |
| 扩展名排序 | 按扩展名字母序（不区分大小写）排列后拼接 |
| 扩展名段 | 每个扩展名也需做非法字符清洗 |
| 过长文件名 | 若完整文件名超过 240 字符，简化为 `统计_{子目录名}_共{N}项.txt`（`N` 为计入统计的文件总数） |
| 重名冲突 | 若目标文件已存在，自动追加 `_1`、`_2`… 后缀序号，**不得覆盖**已有文件 |

示例：

```text
统计_Photos_jpg(24)_mp4(5).txt
统计_2024旅行_无后缀(2)_png(10).txt
```

### 4.3 统计 txt 内容规则

每个 txt 为 UTF-8 文本（建议 `UTF-8 with BOM`，兼容 Windows 记事本），至少包含：

1. **报告头**：标题、根目录路径、子目录路径、生成时间、本次命令行、解析后参数
2. **文件总数**
3. **扩展名数量统计**：按数量降序、扩展名升序列出各类型及个数
4. **整体修改日期范围**（基于文件系统 `mtime`）：
   - 格式：`YYYY_MM_DD`
   - 必须给出**最旧**与**最新**日期（对该子目录内所有计入统计的文件取 min/max）
5. **各扩展名修改日期范围**：每种扩展名分别给出最旧、最新及文件数
6. **说明脚注**：明确统计含子目录所有层级文件，时间取自 `mtime`

无文件子目录时：

- 仍生成统计文件
- 扩展名统计区显示「（无文件）」
- 修改日期范围区显示「无文件，无法计算」

### 4.4 白名单（可选）

- 白名单为空：统计子目录内全部文件
- 白名单非空：仅统计后缀命中项（大小写不敏感；`jpg` 与 `.JPG` 等价）
- 解析支持空格、英文逗号、分号分隔；可自动补全前导点

白名单启用时，扩展名计数与日期范围均只基于命中文件。

## 5. CLI 功能需求

### 5.1 命令行参数

CLI 至少支持以下参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `--root <path>` | 是 | 待统计根目录 |
| `--yes` | 否 | 跳过交互确认，直接执行 |
| `--json-events` | 否 | 输出结构化事件行（供 GUI 解析） |
| `--remove-old-stats` | 否 | **执行统计前**，删除根目录下已有 `统计_*.txt` |
| `--ext-whitelist <text>` | 否 | 文件类型白名单；为空统计全部 |

示例：

```bash
python stat_subdir_by_type.py --root "D:/demo/source_dir"
python stat_subdir_by_type.py --root "D:/demo/source_dir" --yes
python stat_subdir_by_type.py --root "D:/demo/source_dir" --yes --json-events
python stat_subdir_by_type.py --root "D:/demo/source_dir" --yes --remove-old-stats
python stat_subdir_by_type.py --root "D:/demo/source_dir" --yes --ext-whitelist ".jpg .png,.mp4"
```

### 5.2 执行前安全确认

未指定 `--yes` 时，必须提示并等待用户确认。确认信息至少包含：

- 待统计根目录
- 一级子目录数量
- 语义说明：每个子目录对应一个 `统计_*.txt`

用户拒绝后立即退出，退出码为 0（正常取消，非异常）。

### 5.3 输入合法性校验

执行前必须校验：

- 根目录存在
- 根路径是目录

不满足时输出错误并返回非零退出码（建议 `2`）。

### 5.4 清理旧统计文件（`--remove-old-stats`）

在**开始逐个子目录统计之前**执行：

- 扫描范围：仅根目录**直接子项**中的文件（不递归子目录）
- 匹配规则：文件名以 `统计_` 开头且扩展名为 `.txt`（大小写不敏感）
- 操作：逐个 `unlink` 删除
- 日志：输出删除数量

该逻辑与 GUI「清理统计 txt」按钮、勾选「执行前删除…」共用同一实现函数。

### 5.5 单个子目录失败策略

- 某个子目录生成统计失败时，记录错误并**继续**处理其余子目录
- 失败计入 `failed_subdirs`，不导致整体崩溃

## 6. 过程日志与汇总

### 6.1 开头日志（执行元信息）

每次执行开始时输出：

1. 本次实际命令行（`CommandLine:`）
2. 解析后的参数 JSON（`Arguments:`）
3. 根目录路径（`RootDir:`）
4. 若启用清理：已删除旧统计文件数量
5. 待统计子目录数量
6. 白名单状态说明

### 6.2 过程日志（逐子目录）

每个子目录处理完成后输出一条，语义包含：

- 生成的文件名
- 源子目录名
- 文件总数
- 最旧～最新日期范围（有文件时）

空子目录示例语义：`已生成（空目录）：{文件名} <- {子目录名}`

失败示例语义：`[错误] {子目录名}：{错误信息}`

### 6.3 末尾汇总

必须输出 `Summary` 行，至少包含：

| 字段 | 含义 |
|---|---|
| `subdirs` | 一级子目录总数 |
| `generated` | 成功生成的统计文件数 |
| `empty` | 无文件但仍生成统计的子目录数 |
| `failed` | 失败子目录数 |
| `removed_old_stats` | 本次执行前清理的旧统计文件数 |

---

## 7. 结构化事件协议（CLI -> GUI）

当启用 `--json-events` 时，CLI 输出事件行供 GUI 解析：

- **事件行前缀**：`__EVENT__ `（注意末尾有空格）
- **内容**：JSON 对象，含 `event` 字段

事件类型至少包括：

| 事件 | 用途 |
|---|---|
| `log` | 普通日志，`message` 字段 |
| `start` | 任务开始，`total` 为子目录数，可含 `ext_whitelist` |
| `progress` | 进度，`processed` / `total`（按子目录计） |
| `error` | 单个子目录失败，`path`、`message`、`stage` |
| `done` | 最终统计（见 6.3 字段映射） |
| `fatal` | 主流程未捕获异常 |

要求：

- 事件 JSON 使用 `ensure_ascii=True` 编码输出，降低跨平台乱码风险
- GUI 依赖事件流完成日志与进度展示；非事件行也可原样落入日志区

### 7.1 `done` 事件字段（GUI 结果展示）

- `total`：子目录总数
- `generated`：生成文件数
- `empty_subdirs`：空子目录数
- `failed`：失败数
- `removed_old_stats`：清理旧文件数

---

## 8. GUI 功能需求

### 8.1 界面组件

GUI 至少包含：

1. **根目录**输入框 + 「浏览」按钮
2. **说明文案**：将在根目录为每个一级子目录生成 `统计_{子目录名}_扩展名(数量).txt`
3. **文件类型白名单**输入框（留空=全部；示例：`.jpg .png,.mp4`）
4. **复选项**：
   - 执行前删除根目录下已有的 `统计_*.txt`（对应 CLI `--remove-old-stats`）
   - 自动保存配置（对应 `gui_settings.json`）
5. **进度条** + 进度文本（`进度：已处理 / 总数`，按子目录计）
6. **可滚动日志区**（显示全部日志，**不提供**「仅显示警告/错误」过滤）
7. **主按钮**：「开始统计」
8. **辅助按钮**：「清理统计 txt」（见 8.4）

### 8.2 目录拖拽（可选增强）

- 若安装 `tkinterdnd2`，支持将目录拖入根目录输入框
- 未安装时自动回退为浏览选择，并给出提示，不影响主功能

### 8.3 「开始统计」交互流程

1. 校验根目录已填写且存在、为目录
2. 弹窗二次确认：`将在根目录为每个一级子目录生成统计 txt 文件，是否继续？`
3. 禁用「开始统计」按钮，重置进度
4. 后台线程启动子进程调用 CLI（必须带 `--yes --json-events`）
5. 按 `--remove-old-stats`、白名单等当前界面参数组装命令行
6. 实时解析 `__EVENT__` 行，刷新日志与进度
7. 结束后恢复按钮，显示退出码与 `[结果]` 汇总

### 8.4 「清理统计 txt」按钮（独立功能）

与「开始统计」分离，**不启动子进程**，直接调用 CLI 模块中的 `remove_old_stat_files(root_dir)`：

1. 校验根目录（同 8.3）
2. 弹窗确认：`将删除该目录下所有 统计_*.txt 文件：{路径}，是否继续？`
3. 用户确认后执行删除，在日志区输出：`已清理 {N} 个统计 txt 文件：{路径}`
4. 失败时弹窗报错并写 `[错误]` 日志

说明：

- 该按钮可在未勾选「执行前删除…」时单独使用
- 清理范围与 CLI `--remove-old-stats` 完全一致（仅根目录直接文件、前缀 `统计_`、后缀 `.txt`）

### 8.5 GUI 配置持久化

- 配置文件：JSON，默认 `gui_settings.json`，与 `gui_launcher.py` 同目录
- 启动时自动加载；不存在则创建默认配置
- 配置项：

| 键 | 类型 | 说明 |
|---|---|---|
| `root_dir` | string | 根目录 |
| `ext_whitelist` | string | 白名单文本 |
| `remove_old_stats` | bool | 统计前是否删除旧 `统计_*.txt` |
| `auto_save` | bool | 关闭窗口时是否自动保存 |

- `auto_save=true` 时，窗口关闭（`WM_DELETE_WINDOW`）写回当前界面状态
- 支持启动参数 `--settings-file <path>` 指定配置文件（相对路径相对于 GUI 脚本目录）

**明确不要求**：`warn_error_only`（仅显示警告/错误）及相关过滤逻辑。

### 8.6 编码兼容

- 子进程 stdout/stderr 使用系统首选编码解码
- 解码错误字符使用替换策略（如 `errors=replace`），避免 GUI 崩溃

## 9. 启动脚本需求（Windows）

`start_gui.bat` 需满足：

- 双击启动 GUI
- `cd` 到脚本所在目录
- 优先 `py -3 gui_launcher.py`，否则回退 `python gui_launcher.py`
- 命令行参数原样透传（如 `--settings-file`）

---

## 10. 错误处理与稳定性要求

- 单个子目录统计失败不得导致全任务崩溃
- 失败须记录具体子目录与错误信息
- 权限不足、路径异常等须在日志中可见
- 主流程未预期异常：
  - CLI 返回非零退出码
  - 若启用 `--json-events`，输出 `fatal` 事件
- GUI 清理按钮异常：弹窗 + 日志，不崩溃主窗口

---

## 11. 非功能需求

- **一致性**：CLI 与 GUI 的统计口径、清理规则、文件名/内容格式一致
- **可维护性**：核心逻辑在 CLI；GUI 负责参数与展示，统计任务通过子进程调用 CLI
- **可追溯性**：每个统计 txt 内嵌本次命令行与参数，便于事后核对
- **安全性**：不覆盖已有统计文件；删除统计文件前必须经用户确认（CLI 交互或 GUI 弹窗）

---

## 12. 验收标准（可测试清单）

1. 给定根目录含 3 个一级子目录，执行后根目录下生成 3 个 `统计_*.txt`（名称含扩展名计数）
2. 子目录内深层嵌套文件均被计入该子目录对应统计
3. 统计 txt 内容包含整体最旧/最新 `YYYY_MM_DD` 及各扩展名日期范围
4. 无后缀文件在文件名与内容中显示为 `无后缀`
5. 白名单非空时，仅统计命中后缀；未命中文件不计入数量与日期
6. `--remove-old-stats` 仅删除根目录下 `统计_*.txt`，不删其他文件、不递归子目录
7. GUI「清理统计 txt」与 CLI `--remove-old-stats` 删除结果一致
8. 目标统计文件已存在时，新文件以 `_1`、`_2` 命名，不覆盖
9. 单个子目录失败时，其余子目录仍正常生成；`Summary` 中 `failed` 正确
10. GUI 进度条按子目录数更新；`done` 后显示 `[结果]` 汇总
11. GUI 无「仅显示警告/错误」选项；日志区显示完整过程
12. `gui_settings.json` 可保存/加载根目录、白名单、`remove_old_stats`、`auto_save`
13. `start_gui.bat` 可正常启动 GUI 并透传 `--settings-file`
14. Windows 下用记事本打开统计 txt 中文与日期显示正常（UTF-8 BOM）

---

## 13. 非目标（本期不要求）

- 统计根目录自身的文件（仅统计一级子目录）
- 将统计 txt 写入子目录内部
- 统计符号链接指向的目录结构特化
- 按文件内容哈希去重或内容级分析
- 网络盘断线重试、任务队列、多实例并发
- GUI 日志级别过滤（警告/错误专用模式）
- CLI 独立 `--cleanup-only` 参数（清理可由 `--remove-old-stats` 或 GUI 按钮完成；若后续需要可扩展）

## 14. 术语说明

| 术语 | 说明 |
|---|---|
| 根目录 | 用户指定的待统计目录；统计 txt 输出于此 |
| 一级子目录 | 根目录下的直接子文件夹，每个对应一个统计 txt |
| 统计 txt | 以 `统计_` 开头的 `.txt` 报告文件 |
| 扩展名 token | 用于文件名与正文的无点前缀（如 `jpg`），无后缀时为 `无后缀` |
| mtime | 文件系统最后修改时间，日期展示格式为 `YYYY_MM_DD` |
| 白名单 | 可选后缀过滤列表；为空表示不过滤 |

## 15. 与「目录整理工具」的关系

本工具与 `put_in_yymm_order/`（目录整理工具）为**同级独立模块**，实现规格对齐：

- 均提供 CLI + GUI + `start_gui.bat` + `gui_settings.json` + `requirements.txt`
- 均使用 `__EVENT__` 结构化事件供 GUI 解析
- 均支持扩展名白名单解析规则
- **差异**：本工具不移动文件，只读扫描并生成统计报告；GUI 无输出目录、无分目录模式、无「仅显示警告/错误」

## 16. 原始需求摘要（立项依据）

> 遍历指定目录的所有子目录，在指定目录下生成和子目录相同数量的统计 txt 文件；用文件名描述子目录中各类型文件数量，例如 `统计_{子目录名}_jpg(24)_mp4(5).txt`；用文件内容详细描述子目录中所有文件的修改日期范围，最老、最新文件的 `YYYY_MM_DD`。

后续迭代已纳入：

- CLI / GUI 双入口
- 执行前可选清理旧 `统计_*.txt`（CLI 参数 + GUI 勾选）
- GUI 独立「清理统计 txt」按钮
- 配置持久化、拖拽选目录、进度与结构化事件
