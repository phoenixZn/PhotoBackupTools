# 喜爱文件挑选复制工具 - 功能需求文档

## 1. 文档目标

本文档定义「喜爱文件挑选复制工具」的完整功能需求，对应实现目录 `favourite_files_copy_tool/`。  
开发者可仅依据本文档重新实现功能等价的程序，无需参考 `favourite_photo_flag_tool` 源码。

---

## 2. 适用范围与运行环境

| 项 | 要求 |
|---|---|
| 语言 | Python 3.10+ |
| 平台 | **仅 Windows** |
| 路径 | 使用 `pathlib` 或 `os.path` |
| GUI | `tkinter` + `ttk` |
| 图像 | Pillow（图片预览缩放、EXIF 自动旋转） |
| 视频 | OpenCV（`opencv-python-headless`，抽帧缩略图与元信息） |
| 视频降级 | 系统 PATH 中可选 `ffmpeg`（OpenCV 无法解码时抽帧降级） |
| ADB | 复制到安卓时需系统 PATH 中有 `adb`，设备已授权 |

## 4. 核心业务：浏览与标记

### 4.1 Base 目录与遍历顺序

- 用户通过 GUI 选择 **Base 目录**（照片/视频根目录）。
- 工具按 **深度优先（DFS）** 收集可预览媒体文件：
  1. 当前目录下所有媒体文件（按文件名不区分大小写排序，图片与视频混排）；
  2. 再依次进入各子目录（子目录名排序），递归同样规则。
- 支持图片扩展名：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.webp`、`.gif`。
- 支持视频扩展名：`.mp4`、`.mov`、`.mkv`、`.avi`、`.webm`、`.m4v`。
- 每条记录携带 `media_kind`：`image` 或 `video`。
- 全局维护扁平列表，翻页在该列表上按序号进行。

### 4.2 GUI 顶部信息

- **Base 目录**：显示用户选择的根路径。
- **当前子目录**：显示当前预览文件所在目录的绝对路径；无文件时显示 `-`。
- 加载 Base 后，日志与状态栏显示：`共 N 个文件（图片 X，视频 Y）`。

### 4.3 预览

**通用**

- 按预览区域大小自动缩放（`thumbnail`，LANCZOS）。
- 窗口缩放时防抖重绘（约 120ms）。

**图片（`media_kind == image`）**

- 使用 Pillow 打开并预览。
- 根据 EXIF 方向 **自动旋转**（`ImageOps.exif_transpose`）。

**视频（`media_kind == video`）**

- 使用 OpenCV `VideoCapture` 抽帧生成缩略图：
  1. 优先读取第 0 帧；
  2. 若失败或帧近乎全黑，seek 到 `min(1.0, duration/2)` 秒处再读一帧；
  3. BGR 转 RGB 后交给 Pillow / `ImageTk` 显示。
- OpenCV 失败且系统 PATH 存在 `ffmpeg` 时，降级执行：

```text
ffmpeg -ss 1 -i <file> -vframes 1 -f image2pipe -vcodec png pipe:1
```

- 抽帧结果经 LRU **内存缓存**（约 64 条；键为路径 + mtime + 预览区尺寸）；重复浏览同一视频应明显更快。
- 预览失败时不阻塞标记/复制；界面显示占位提示（如「无法预览视频，请用系统打开」），用户可通过「打开文件」用系统默认播放器查看。
- 不在 GUI 内嵌完整视频播放；GIF 仍只显示第一帧（不播放动画）。

### 4.4 喜爱清单 `favourite_list.txt`

- 保存在 **文件所在子目录**（非 Base 根），除非文件直接在 Base 根下则写在 Base 根。
- 每行一个 **文件名 only**（不含路径、不含子目录前缀）；图片与视频可混存于同一清单。
- UTF-8；有内容时末尾换行。
- 标记/取消喜爱后 **立即落盘**。
- 写入顺序：优先按当前 DFS 扁平列表中该目录内文件出现顺序，其余按名称排序。

### 4.5 浏览位置 `preview_pos.txt`

- 保存在 **Base 根目录**。
- 单行：相对 Base 的路径，分隔符统一为正斜杠 `/`（如 `DirA/DirB/photo1.jpg` 或 `DirA/clip.mp4`）。
- 每次切换当前文件后立即写入。
- 重新打开同一 Base 时，在扁平列表中匹配该行以恢复索引；无匹配则从第一项开始。

### 4.6 信息显示

**图片**至少展示：

- 文件名、类型（图片）
- 全局序号（当前/总数）
- 相对 Base 路径
- 分辨率
- 文件大小（人类可读）
- 修改时间
- EXIF 拍摄时间（无则「无」）
- 是否喜爱（是/否）及醒目状态标签

**视频**至少展示：

- 文件名、类型（视频）
- 全局序号（当前/总数）
- 相对 Base 路径
- 分辨率（来自 OpenCV 视频流属性）
- 时长（`MM:SS` 或 `HH:MM:SS`；无法读取时「未知」）
- 帧率（无法读取时「未知」）
- 文件大小、修改时间
- 是否喜爱（是/否）及醒目状态标签

## 5. Target 与复制

### 5.1 Target 模式（GUI 双模式）

- **PC 模式**：文本框 +「选择 Target」目录对话框。
- **安卓模式**：独立文本框输入手机路径（如 `/sdcard/PhotoBackup`），必须以 `/` 开头；PC 选择按钮禁用。
- **带路径复制** 勾选框，默认未勾选。

### 5.2 目标路径规则

设源文件绝对路径为 `src`，相对 Base 为 `rel`（如 `DirA/DirB/photo1.jpg` 或 `DirA/clip.mp4`），Target 根为 `T`：

| 带路径复制 | PC 目标 | 安卓目标 |
|---|---|---|
| 勾选 | `T/DirA/DirB/photo1.jpg` | `T/DirA/DirB/photo1.jpg`（POSIX） |
| 未勾选 | `T/photo1.jpg` | `T/photo1.jpg` |

复制前创建必要的父目录（PC：`mkdir -p`；安卓：`adb shell mkdir -p`）。  
复制逻辑与扩展名无关，图片与视频使用相同规则。

### 5.3 PC 复制约束

- 使用 `shutil.copy2`，尽量保留修改时间。
- **禁止覆盖**：若目标路径已存在文件，不复制，并在日志输出：

```text
冲突：目标已存在同名文件，拒绝覆盖
  源: <源绝对路径> (<大小>)
  目标: <目标绝对路径> (<大小>)
```

- 扁平模式下，不同子目录的同名文件复制到同一 Target 时，后者视为冲突。

### 5.4 安卓复制

- 复制前检查 `adb` 与设备就绪。
- 优先 `adb push --sync <local> <remote>`；不支持 `--sync` 时降级 `adb push` 并警告。
- 需求仅强制 PC 不覆盖；安卓以 push/`--sync` 语义为准，失败写入日志。

### 5.5 复制按钮

| 按钮 | 行为 |
|---|---|
| **CopyCurFile** | 复制当前预览文件到 Target |
| **CopyFavouriteFiles** | 遍历 Base 下所有目录（DFS 目录列表）；若存在 `favourite_list.txt`，将其中的文件名解析为 `该目录/文件名` 逐条复制；统计成功/冲突/缺失/失败 |

长任务在后台线程执行，期间禁用复制按钮，结果写入 **GUI 日志区**。

## 6. GUI 日志区

- 底部 `ScrolledText`，只读展示。
- 每条带时间戳 `[HH:MM:SS]`。
- 记录：加载 Base（含图片/视频计数）、标记变化、复制开始/成功/冲突/失败、adb 警告等。

## 7. 启动方式

```bash
pip install -r requirements.txt
py -3 favourite_files_app.py
# 或
py -3 favourite_files_app.py "E:\Photos\Base"
# 或双击 run.bat
# 开发测试：双击 test_run.bat（内部调用 run.bat 并传入预设 Base）
```

**依赖检测（`run.bat`）**

- 启动前检测 `PIL` 与 `cv2`；缺失时自动执行 `pip install -r requirements.txt`。
- 推荐使用 `py -3` 启动，避免 Windows 商店版 `python` 与已安装 OpenCV 的解释器不一致导致视频无法预览。

- [ ] 选择 Base 后 DFS 顺序正确（同层文件先于子目录；图片与视频按文件名混排）
- [ ] GUI 同时显示 Base 与当前子目录；加载日志含图片/视频数量
- [ ] 图片预览：自动缩放与 EXIF 旋转正常
- [ ] 视频预览：OpenCV 抽帧缩略图正常；失败时尝试 ffmpeg；仍失败则占位提示且「打开文件」可用
- [ ] 重复浏览同一视频命中内存缓存，无明显重复卡顿
- [ ] 视频可翻页、标记/取消喜爱；`favourite_list.txt` 写入文件名且与图片可混存
- [ ] `Base/preview_pos.txt` 可保存/恢复图片与视频的相对 Base 路径
- [ ] 视频信息栏显示分辨率、时长、帧率（可读时）
- [ ] 快捷键与按钮翻页、目录跳转、标记正常
- [ ] PC Target：带路径/不带路径目标正确；图片与视频均可复制
- [ ] PC 目标已存在同名文件时不覆盖并打印双路径与大小
- [ ] CopyFavouriteFiles 汇总所有子目录喜爱清单（含视频条目）
- [ ] 安卓 Target：push 使用 `--sync`（或降级提示）
- [ ] 日志区同步显示操作信息
- [ ] 不修改 `favourite_photo_flag_tool` 及其他目录

## 9. 与老版 `favourite_photo_flag_tool` 差异摘要

| 项 | 老版 | 本工具 |
|---|---|---|
| 浏览范围 | 单目录 `rglob` 扁平排序 | Base + DFS |
| 媒体类型 | 仅图片 | 图片 + 常见视频格式 |
| 视频预览 | 无 | OpenCV 抽帧 + 可选 ffmpeg 降级 |
| favourite_list | 当前目录、相对路径 | 各子目录、仅文件名 |
| preview_pos | 当前目录、相对路径 | Base 根、相对 Base 路径 |
| 复制 / Target / 日志 | 无 | 有 |
| 预览旋转 | 无 | 图片 EXIF transpose |

## 10. 已知限制

- **编码兼容性**：部分 H.265 或特殊封装可能 OpenCV 与 ffmpeg 均无法抽帧；此时仅影响 GUI 预览，不影响标记与复制。
- **大视频首次打开**：同步抽帧可能短暂阻塞 UI；缓存后翻回同一文件应无感。
- **GIF**：仍只显示第一帧，不播放动画。
