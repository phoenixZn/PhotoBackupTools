# 喜爱文件挑选复制工具 - 功能需求文档

## 1. 文档目标

本文档定义「喜爱文件挑选复制工具」的完整功能需求，对应实现目录 `favourite_files_copy_tool/`。  
开发者可仅依据本文档重新实现功能等价的程序，无需参考 `favourite_photo_flag_tool` 源码。

---

## 2. 适用范围与运行环境

| 项 | 要求 |
|---|---|
| 语言 | Python 3.10+ |
| 平台 | **仅 Windows** |
| 路径 | 使用 `pathlib` 或 `os.path` |
| GUI | `tkinter` + `ttk` |
| 图像 | Pillow（预览缩放、EXIF 自动旋转） |
| ADB | 复制到安卓时需系统 PATH 中有 `adb`，设备已授权 |

## 4. 核心业务：浏览与标记

### 4.1 Base 目录与遍历顺序

- 用户通过 GUI 选择 **Base 目录**（照片根目录）。
- 工具按 **深度优先（DFS）** 收集可预览图片：
  1. 当前目录下所有图片文件（按文件名不区分大小写排序）；
  2. 再依次进入各子目录（子目录名排序），递归同样规则。
- 支持扩展名：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.webp`、`.gif`。
- 全局维护扁平列表，翻页在该列表上按序号进行。

### 4.2 GUI 顶部信息

- **Base 目录**：显示用户选择的根路径。
- **当前子目录**：显示当前预览图片所在目录的绝对路径；无图时显示 `-`。

### 4.3 预览

- 按预览区域大小自动缩放（`thumbnail`，LANCZOS）。
- 根据 EXIF 方向 **自动旋转**（`ImageOps.exif_transpose`）。
- 窗口缩放时防抖重绘（约 120ms）。

### 4.4 喜爱清单 `favourite_list.txt`

- 保存在 **图片所在子目录**（非 Base 根），除非文件直接在 Base 根下则写在 Base 根。
- 每行一个 **文件名 only**（不含路径、不含子目录前缀）。
- UTF-8；有内容时末尾换行。
- 标记/取消喜爱后 **立即落盘**。
- 写入顺序：优先按当前 DFS 扁平列表中该目录内文件出现顺序，其余按名称排序。

### 4.5 浏览位置 `preview_pos.txt`

- 保存在 **Base 根目录**。
- 单行：相对 Base 的路径，分隔符统一为正斜杠 `/`（如 `DirA/DirB/photo1.jpg`）。
- 每次切换当前图片后立即写入。
- 重新打开同一 Base 时，在扁平列表中匹配该行以恢复索引；无匹配则从第一张开始。

### 4.6 信息显示

当前图片至少展示：

- 文件名  
- 全局序号（当前/总数）  
- 相对 Base 路径  
- 分辨率  
- 文件大小（人类可读）  
- 修改时间  
- EXIF 拍摄时间（无则「无」）  
- 是否喜爱（是/否）及醒目状态标签

| 操作 | 快捷键 | 按钮 |

- 界面展示本次运行相对打开 Base 时的新增/取消标记列表。
- 可勾选关闭窗口时在 `Base/.logs/favourite_changes_<时间戳>.txt` 记录变化。

## 5. Target 与复制

### 5.1 Target 模式（GUI 双模式）

- **PC 模式**：文本框 +「选择 Target」目录对话框。
- **安卓模式**：独立文本框输入手机路径（如 `/sdcard/PhotoBackup`），必须以 `/` 开头；PC 选择按钮禁用。
- **带路径复制** 勾选框，默认未勾选。

### 5.2 目标路径规则

设源文件绝对路径为 `src`，相对 Base 为 `rel`（如 `DirA/DirB/photo1.jpg`），Target 根为 `T`：

| 带路径复制 | PC 目标 | 安卓目标 |
|---|---|---|
| 勾选 | `T/DirA/DirB/photo1.jpg` | `T/DirA/DirB/photo1.jpg`（POSIX） |
| 未勾选 | `T/photo1.jpg` | `T/photo1.jpg` |

复制前创建必要的父目录（PC：`mkdir -p`；安卓：`adb shell mkdir -p`）。

### 5.3 PC 复制约束

- 使用 `shutil.copy2`，尽量保留修改时间（文件内容含 EXIF 不变）。
- **禁止覆盖**：若目标路径已存在文件，不复制，并在日志输出：

```text
冲突：目标已存在同名文件，拒绝覆盖
  源: <源绝对路径> (<大小>)
  目标: <目标绝对路径> (<大小>)
```

- 扁平模式下，不同子目录的同名文件复制到同一 Target 时，后者视为冲突。

### 5.4 安卓复制

- 复制前检查 `adb` 与设备就绪。
- 优先 `adb push --sync <local> <remote>`；不支持 `--sync` 时降级 `adb push` 并警告。
- 需求仅强制 PC 不覆盖；安卓以 push/`--sync` 语义为准，失败写入日志。

### 5.5 复制按钮

| 按钮 | 行为 |
|---|---|
| **CopyCurFile** | 复制当前预览文件到 Target |
| **CopyFavouriteFiles** | 遍历 Base 下所有目录（DFS 目录列表）；若存在 `favourite_list.txt`，将其中的文件名解析为 `该目录/文件名` 逐条复制；统计成功/冲突/缺失/失败 |

长任务在后台线程执行，期间禁用复制按钮，结果写入 **GUI 日志区**。

## 6. GUI 日志区

- 底部 `ScrolledText`，只读展示。
- 每条带时间戳 `[HH:MM:SS]`。
- 记录：加载 Base、标记变化、复制开始/成功/冲突/失败、adb 警告等。

- [ ] `Base/preview_pos.txt` 为相对 Base 路径，重启后续看

- [ ] PC Target：带路径/不带路径目标正确

- [ ] CopyFavouriteFiles 汇总所有子目录喜爱清单

## 9. 与老版 `favourite_photo_flag_tool` 差异摘要

| 项 | 老版 | 本工具 |
|---|---|---|
| 浏览范围 | 单目录 `rglob` 扁平排序 | Base + DFS |
| favourite_list | 当前目录、相对路径 | 各子目录、仅文件名 |
| preview_pos | 当前目录、相对路径 | Base 根、相对 Base 路径 |
| 复制 / Target / 日志 | 无 | 有 |
| 预览旋转 | 无 | EXIF transpose |
